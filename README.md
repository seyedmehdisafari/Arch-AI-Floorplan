## 📌 Overview

This project presents an end-to-end implementation of Semantic Image Segmentation for architectural floor plans using a custom-designed U-Net architecture trained on the RPlan Dataset.

The model learns to infer and reconstruct functional residential spaces—including bedrooms, living rooms, kitchens, bathrooms, and circulation areas—using only the structural wall information extracted from floor plan layouts.

The objective is to investigate how deep convolutional neural networks can understand spatial organization and architectural semantics directly from building geometry.

## 🏗️ Architecture

The project employs a modified U-Net encoder-decoder structure:

text Input Wall Mask        │        ▼ Encoder Blocks        │        ▼ Bottleneck Layer        │        ▼ Decoder Blocks + Skip Connections        │        ▼ Semantic Room Reconstruction 

### Core Components

- Convolutional feature extraction
- Max-pooling downsampling
- Skip connections for spatial preservation
- Transposed convolutions for upsampling
- Pixel-wise reconstruction loss optimization
